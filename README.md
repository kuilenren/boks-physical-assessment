# BOKS（搏克斯）儿童体测与体态健康平台

这是一套面向 BOKS 自有学生及其家长的产品研发基线文档。产品以体测数据和立体姿态照片为输入，生成可追溯的体测评分、体态观察报告、运动训练建议与阶段计划，并提供 BOKS 内部内容、知识库和安全审核后台。

> **文档状态：**研发前方案  
> **研究基线：**2026-08-01（Asia/Shanghai）  
> **重要边界：**第一版体态功能是非诊断性姿态观察和健康教育工具，不替代医生、影像检查或康复治疗。

## 产品定位

- 小学至高中：按教育部《国家学生体质健康标准（2014年修订）》的学段、年级、性别和版本配置评分。
- 幼儿园：不套用小学体测分数，使用幼儿专项体能参考、成长观察和训练进步记录。
- 体态：通过前、后、左、右及必要的动态拍摄进行姿态质量检查、关键点分析和风险提示。
- 训练：输出年龄、学段、测试结果、姿态表现、运动禁忌和可用场地约束下的训练建议。
- 知识库：保存官方原文、版本、哈希、适用人群、算法映射和审核记录；自动发现不等于自动发布。

## 研发原则

1. **标准先于算法。**任何评分或阈值都必须关联来源、版本、原文和审核记录。
2. **原始值与解释分离。**保存原始测量值、算法结果和展示文案，不能只保存最终分数。
3. **筛查不冒充诊断。**普通照片不能推导 Cobb 角，不能用报告替代医疗检查。
4. **监护人可控。**未成年人数据默认取得监护人同意，支持查看、导出、撤回和删除。
5. **不把自动抓取当作自动生效。**抓取失败、来源变化或规则冲突必须进入人工审核。
6. **训练建议要能执行。**每项训练包含动作、频次、强度、时长、替代动作、停止条件和进度指标。

## 首版交付边界

### P0（可上线闭环）

- 家长登录、监护人同意、儿童档案和多儿童切换。
- 小学至高中手工体测录入、校验、评分、报告和 PDF/图片分享。
- 幼儿体能参考与进步记录，不显示未经核验的国家总评。
- 四视角拍摄引导、照片质量检查、姿态观察报告和家长就医提示。
- 年龄分层的低风险训练计划、打卡和家长确认。
- 专业知识库后台上传、审核、发布、回滚和审计。
- 文本 AI 咨询；语音输入/播报和图片上下文在同一安全策略下运行。

### P1（增强）

- 动态动作视频、重复测试对比和设备端姿态推理。
- 多端同步、家庭成员权限、训练进度和数据导出。

### 当前明确不做

- 不建设医疗机构合作、人工转诊或医疗服务闭环。
- 不建设学校/第三方机构的班级管理、机构订阅或外部教师端。
- 不开发临床筛查工具、医疗诊断功能或医疗软件功能。

## 开发前置条件

- 取得并保存教育部《国家学生体质健康标准（2014年修订）》及评分附件的正式文件。
- 取得 WS/T 423—2022 和 GB/T 16133—2014 等现行全文或合法授权版本。
- 核验国家体育总局《国民体质测定标准手册（幼儿部分）》的原版评分表；未核验前不得编造幼儿总评。
- 完成未成年人个人信息保护影响评估、BOKS 家长授权文本和数据处理制度。
- 对照片分析定位、模型性能、非诊断边界和训练文案进行专业评审。
