# 02 功能板块与验收规格

## 1. 功能地图

```text
身份与家庭
  ├─ 监护人登录 / 同意 / 家庭成员
  └─ 儿童档案 / 健康问卷 / 权限
体测中心
  ├─ 标准选择 / 数据录入 / 导入
  ├─ 评分引擎 / 历史趋势 / 报告
  └─ 训练目标 / 训练计划 / 打卡
体态中心
  ├─ 拍摄引导 / 质量门禁 / 四视角任务
  ├─ 关键点分析 / 风险提示 / 报告
  └─ 体态训练 / 复测对比 / 家长就医提示
智能咨询
  ├─ 文本 / 语音 / 图片上下文
  ├─ 知识引用 / 安全策略 / 人工升级
  └─ 对话记录 / 删除 / 反馈
BOKS 内部后台
  ├─ 标准知识库 / 训练内容 / 版本发布
  ├─ 家长请求 / 风险文案 / 反馈工单
  └─ 审计 / 监控 / 数据请求
```

## 2. 账号、家庭与儿童档案

### FR-001 监护人登录

- 支持微信登录；App 支持手机号/设备安全登录。
- 登录后创建 `guardian`，不以儿童账号代替监护人。
- 监护人必须完成隐私政策阅读和儿童数据处理授权后才能上传体测照片或健康数据。
- 授权记录保存协议版本、时间、主体、来源平台、IP/设备摘要和撤回状态。

### FR-002 儿童档案

必填：昵称、出生日期、性别、学段/年级。可选：身高、体重、BOKS 课程组/训练目标。健康问卷只收集生成安全建议所必要的项目。

规则：

- 年龄按测量日期计算，保存 `age_in_months` 快照。
- 学段和年级可手动修正，但必须记录修改人和原因。
- “性别”仅用于标准表选择，报告文案避免把性别变成价值判断。
- 删除儿童档案时，级联删除或匿名化报告、原图、训练和对话，保留法律要求的最小审计记录。

## 3. 体测数据录入

### FR-101 项目展示

服务端返回当前版本允许的项目、单位、精度、测量方法、最大尝试次数、是否必填和输入帮助。客户端不得根据本地 if/else 自行推断项目。

### FR-102 数据校验

校验层级：

1. 客户端格式校验：数字、单位、精度、非负数。
2. 服务端业务校验：年龄/学段、性别、项目组合和合理范围。
3. 评分引擎校验：是否存在评分表、版本是否可用、缺测/免测状态是否合法。

错误必须显示具体项目和修正建议；不得把无法评分的项目静默当作 0。

### FR-103 体测记录状态

```text
draft -> submitted -> validating -> scored -> reported
                       ├-> rejected
                       └-> needs_review
```

- `draft`：本地/服务端草稿。
- `submitted`：用户提交，输入快照锁定。
- `validating`：服务端验证。
- `scored`：评分完成，等待报告渲染。
- `reported`：报告可查看。
- `rejected`：数据不合法，保留原因。
- `needs_review`：免测、异常值或规则冲突，进入人工队列。

## 4. 体测评分和报告

### FR-201 评分

评分计算必须使用：

```text
score_input_snapshot
  + standard_version
  + scoring_table_version
  + algorithm_version
  + rule_evaluation_trace
```

小学至高中：

- 标准分满分 100；
- 附加分上限 20；
- 总分上限 120；
- 90.0+ 优秀，80.0—89.9 良好，60.0—79.9 及格，59.9 及以下不及格。

具体单项分档、项目组合、权重和附加分表从知识库读取，不能内嵌在客户端或散落在业务代码。

### FR-202 体测报告结构

1. 报告摘要：测量日期、标准版本、总分/等级、数据完整度。
2. 单项卡片：原始值、单位、单项分、权重、同组参考、解释。
3. 优势与优先项：最多 3 个优势、最多 3 个优先改善项。
4. 变化趋势：同一指标历史变化；提示测量条件差异。
5. 训练建议：目标、周期、频次、动作和安全边界。
6. 数据来源：标准名称、文号/编号、发布日期、生效日期、官方链接。
7. 限制说明：非医疗建议、数据质量和缺测信息。

### FR-203 幼儿模式

- 3—6 岁显示幼儿体能项目、原始值、练习表现和趋势。
- 未取得《国民体质测定标准手册（幼儿部分）》合法原版评分规则前，不显示国家总分或“优秀/不及格”。
- 采用《3—6岁儿童学习与发展指南》时，文案标为“发展目标参考”，不称为国家体测分数。

## 5. 体态拍摄

### FR-301 拍摄前检查

页面必须显示：

- 适用年龄和非诊断声明；
- 服装、鞋袜、光线、距离、相机高度和背景要求；
- 监护人授权、照片用途、保存期限、删除入口；
- 不适合拍摄或需就医的情况。

### FR-302 四视角任务

默认任务：

1. 正面站立；
2. 背面站立；
3. 左侧站立；
4. 右侧站立。

可选任务：

- 前屈动作（需专业协议和更严格质量检查）；
- 步态/动态动作（P1，不纳入 P0 诊断性结论）。

每张照片保存拍摄方向、设备、焦距/视场角（可用时）、分辨率、姿态质量分和上传授权版本。

### FR-303 质量门禁

质量失败必须返回一个或多个具体原因：

- 人体未完整出现；
- 目标太远/太近；
- 相机倾斜；
- 光照过暗/过曝；
- 关键部位遮挡；
- 站姿不符合要求；
- 背景或多人干扰；
- 方向与任务不匹配。

质量门禁不通过时，不生成姿态风险等级；用户可以重拍或取消。

## 6. 体态报告

### FR-401 报告内容

- 拍摄条件和四视角缩略图（默认去脸/模糊）；
- 关键点覆盖率和置信度；
- 左右肩/骨盆/躯干偏移等姿态观察指标；
- 头颈姿态指标（若符合 TY/T 501 测量条件）；
- 观察性描述、风险提示和复核建议；
- 训练建议、替代动作、停止条件；
- “普通照片不能诊断疾病”的醒目限制；
- 报告版本和模型版本。

### FR-402 风险分层

| 层级 | 展示 | 行动 |
| --- | --- | --- |
| A | 未发现明显照片层面不对称 | 维持活动，按计划复测 |
| B | 存在轻度观察差异或置信度不足 | 优先改善拍摄条件，必要时人工复核 |
| C | 明显不对称/多视角一致或有主诉 | 建议家长自行带孩子到正规医疗机构筛查；BOKS 不提供医疗服务 |
| D | 疼痛、麻木、无力、步态异常等红旗 | 停止训练，尽快就医 |

上述层级是产品行动层，不得映射为医学疾病等级。

## 7. 训练规划

### FR-501 计划生成

输入：

- 年龄（月）、学段、性别（仅评分需要时）；
- 体测优先项和趋势；
- 体态观察项和置信度；
- 训练目标、每周可用天数、单次时长、场地和器材；
- 健康问卷、禁忌、疼痛和医生建议；
- 内容版本和安全规则版本。

输出：

- 4—8 周周期；
- 每周频次和每日训练时长；
- 热身、主训练、放松；
- 组数、次数、节奏、休息和替代动作；
- 动作要点、常见错误和停止条件；
- 周测指标和复测提醒。

### FR-502 训练安全

出现疼痛、麻木、无力、夜间疼痛、呼吸困难、明显运动耐量下降或快速姿态变化时：

- 不输出强化训练；
- 显示停止训练和就医提示；
- 允许记录专业人员意见；
- 训练计划状态改为 `paused_safety_review`。

## 8. 智能咨询、语音和多模态

### FR-601 对话

- 文本输入支持体测报告、训练计划和已授权照片作为上下文。
- 用户主动选择报告/照片后才加入上下文。
- AI 回答显示引用的知识库版本；无可靠来源时明确说不知道。
- 问题分类：体测解释、动作方法、训练安排、姿态观察、风险/就医、隐私/账号。

### FR-602 语音

- 语音上传前征得麦克风授权；
- ASR 转写允许用户编辑确认；
- TTS 播报提供同步文字；
- 音频默认短期保存并支持删除；
- 语音内容含医疗急症时走安全规则，不继续闲聊。

### FR-603 多模态

- 图片只能作为已授权的分析上下文，不默认进入模型训练；
- 对话模型不能直接读取未经质量门禁的体态照片并下诊断结论；
- 视觉模型输出必须经过结构化安全层，文本模型只消费结构化结果和可引用证据。

## 9. 知识库后台

### FR-701 来源登记

字段：来源机构、标题、文号/编号、版本、发布日期、生效日期、官方 URL、获取时间、文件哈希、适用人群、证据等级、版权/授权状态、替代关系和备注。

### FR-702 审核发布

状态：

```text
discovered -> fetched -> parsed -> candidate -> reviewed -> published
                                         ├-> rejected
published -> superseded
published -> withdrawn
```

评分规则、医疗边界和未成年人安全文案至少需要两名不同账号审核。发布后只生成新版本，禁止覆盖历史版本。

## 10. BOKS 内部后台

- 仅供 BOKS 内部内容、知识库、运营和安全人员使用。
- 内部人员按工单查看最小必要数据，默认不能下载学生原图。
- 家长反馈、风险文案、规则发布和删除请求均需审计。
- 不提供学校或第三方组织功能、班级管理、教师端、组织订阅或数据共享。

## 11. 通知

- 体测报告完成、照片质量失败、计划开始、复测提醒、知识库版本生效。
- 医疗风险提示不使用营销话术。
- 儿童数据相关通知发送给监护人，不直接向儿童索取敏感信息。

## 12. 验收清单

- [ ] 所有敏感接口在监护人同意前不可调用。
- [ ] 小学至高中报告能展示标准版本和计算轨迹。
- [ ] 幼儿模式不显示未经核验的国家总评。
- [ ] 四视角任一质量失败会阻止风险等级生成。
- [ ] 体态报告包含非诊断限制和家长就医提示。
- [ ] AI 无知识库依据时不会编造阈值。
- [ ] 删除请求覆盖原图、派生图、向量、缓存、索引和备份策略。
- [ ] 知识库发布可回滚，历史报告结果保持可解释。
