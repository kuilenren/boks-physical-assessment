# 11 安全、隐私与合规文档

## 1. 合规定位

BOKS 第一版定位为：

- 儿童青少年体测记录、标准化评分和运动训练辅助；
- 非诊断性身体姿态观察；
- BOKS 家庭的健康教育工具。

是否构成医疗器械软件，取决于预期用途、功能、算法、宣传和输出结果，不能只靠“不构成医疗建议”一句免责声明解决。当前版本明确不提供医疗诊断、临床筛查或医疗软件功能。

## 2. 主要法规和规范

| 文件 | 设计影响 |

| 《儿童个人信息网络保护规定》 | 监护人同意、专门规则、最小必要、访问更正删除和安全 |
| 《网络安全法》《数据安全法》 | 网络安全、数据分类、事件处置和平台责任 |
| GB/T 35273—2020 | 个人信息处理的实践参考 |
| GB/T 39335—2020 | 个人信息保护影响评估参考 |
| GB/T 42574—2023 | 个人信息保护合规审计参考 |
| 《医疗器械监督管理条例》 | 医疗器械软件属性和监管边界 |
| NMPA AI 医用软件/医疗器械软件指导原则 | 医疗算法软件的分类、验证和注册路径 |

正式发布前由法务确认当前有效版本、行业/地方要求和 BOKS 家长服务协议责任。

## 3. 数据分类

| 等级 | 数据 | 默认处理 |
| --- | --- | --- |
| S3 极敏感 | 儿童原图、音频、健康问卷、姿态/健康推断、医疗资料 | 监护人单独同意，私有存储，加密，最小访问 |
| S2 敏感 | 体测原始值、报告、训练记录、聊天内容、设备元数据 | 授权范围内访问，审计和期限删除 |
| S1 个人 | 昵称、出生日期、账号、BOKS 课程关系 | 加密/脱敏，按角色访问 |
| S0 公共 | 产品说明、公开动作内容、标准链接元数据 | 不含儿童数据和私有原文 |

照片是否构成人脸/生物识别信息要看是否用于身份识别或提取生物特征；产品按最严格的敏感数据策略处理照片和姿态推断。

## 4. 监护人同意流程

### 4.1 首次使用

1. 说明产品用途、非诊断边界和适用年龄。
2. 监护人阅读隐私政策、儿童个人信息专门说明和用户协议。
3. 分开列出必要账号数据、体测数据、照片、音频、AI 上下文和 BOKS 内部支持访问。
4. 监护人确认与儿童关系和授权范围。
5. 记录协议/指引版本、时间、平台、证据哈希和撤回入口。

### 4.2 分项授权

- `assessment_data`：体测记录和报告；
- `photo_analysis`：原图上传、姿态分析和派生关键点；
- `audio_processing`：录音、ASR、TTS；
- `ai_context`：将已选择的报告/图片/训练记录加入咨询上下文；
- `boks_internal_support`：BOKS 内部处理家长反馈/安全工单所需的字段和期限；
- `model_training`：默认关闭，若未来需要须另行取得明确同意，且不能以使用核心功能为前提。

### 4.3 撤回

撤回后：

- 立即阻止新的对应数据采集和处理；
- 进行中的任务取消或删除；
- 监护人可以查看、导出或删除既有数据；
- 已生成的聚合统计只在无法反推个人时保留；
- 记录撤回时间、范围和执行结果。

## 5. 隐私政策必须说明

- 数据控制者/处理者和联系方式；
- 收集字段、目的、必要性和处理方式；
- 儿童/监护人角色和监护人同意；
- 照片、音频、姿态关键点和健康推断；
- 是否使用第三方云、模型、ASR/TTS、对象存储和分析 SDK；
- 数据跨境、委托处理和子处理者；
- 保存期限、备份清理和删除；
- 查看、更正、导出、撤回、删除和投诉；
- 风险、误差、非诊断性和家长自行就医提示；
- 安全措施、事件通知和版本更新方式。

不能在隐私政策里使用“用于改善服务”作为无限期模型训练的笼统授权。

## 6. 访问控制

### 6.1 家庭

- 监护人只能查看自己授权的儿童；
- 多监护人按 `scope` 分配报告、照片、训练和导出权限；
- 儿童不能独立授权照片或导出敏感数据；
- 删除需要二次确认和监护人验证。

### 6.2 BOKS 内部

- 内容、运营和审核人员只能按工单查看最小必要数据；
- 原图、聊天全文、健康问卷和医疗资料默认不可见；
- 原始数据和导出操作需要额外授权、期限和审计；
- BOKS 内部人员不能绕过监护人撤回或删除请求。

### 6.3 后台

- 审核员查看标准原文和结构化规则，不默认查看儿童原图；
- 姿态专业复核员按工单查看最小必要素材，访问自动到期；
- 安全审计员看访问记录和哈希，不看内容；
- 超级管理员执行紧急下线和恢复，但必须双人复核。

## 7. 技术安全控制

- TLS 1.2+；服务间 mTLS 或私有网络；
- 数据库和对象存储服务端加密；
- KMS 分层密钥、轮换和访问审计；
- WAF、API 限流、设备/IP 风险识别；
- 上传 MIME、大小、扩展名、哈希和恶意文件检查；
- 预签名 URL 最短有效期，禁止公开桶；
- 内容安全检查，不在日志保存原文；
- 依赖、镜像和移动端 SDK 漏洞扫描；
- 管理后台 MFA、最小权限、强制操作理由；
- 生产数据禁止进入本地开发和演示环境。

## 8. 威胁建模

| 威胁 | 例子 | 控制 |
| --- | --- | --- |
| 越权查看儿童 | 修改 child_id 访问他人报告 | 服务端租户/家庭授权检查、IDOR 测试 |
| 原图泄露 | 公开对象存储或长效 URL | 私有桶、短签名、下载审计 |
| 伪造体测分数 | 客户端传入 score | 服务端规则引擎、输入快照和签名 |
| 提示词注入 | 知识库/图片指示 AI 忽略安全规则 | 内容隔离、结构化检索、安全后处理 |
| 恶意文件 | 上传脚本或超大图片 | allowlist、病毒扫描、隔离转码 |
| 规则污染 | 抓取错误或虚假网站 | 官方域名 allowlist、哈希、双人审核 |
| 删除不彻底 | 缓存/备份/向量残留 | 删除编排任务、到期清理证明 |
| 供应链风险 | 第三方 SDK 采集儿童数据 | SDK 清单、最小权限、合同和审计 |

## 9. 医疗和宣传边界

### 允许的表述

- “姿态观察”
- “照片层面的不对称提示”
- “建议复拍；必要时由家长自行带孩子到正规医疗机构筛查”
- “运动训练辅助”
- “本结果不能诊断疾病”

### 禁止的表述

- “AI 诊断脊柱侧弯/颈椎病/扁平足”
- “精准测量 Cobb 角”
- “替代 X 光、医生或康复治疗师”
- “保证矫正/治愈/治疗”
- “根据照片开具矫形器或治疗处方”

体态分析和训练文案、商店截图、客服话术、AI 提示词必须使用同一套禁用词规则。

## 10. 数据主体请求

支持：

- 查看收集的数据和授权；
- 更正儿童档案；
- 导出体测、报告和训练记录；
- 删除照片、音频、对话、报告或完整儿童档案；
- 撤回指定用途；
- 解释自动化结果的来源、版本和限制；
- 投诉和人工复核。

流程：

```text
request -> verify guardian -> scope preview -> confirmation
        -> async erase/export -> per-system verification
        -> completion evidence -> notify guardian
```

高风险请求必须有人工复核；拒绝时说明法律或合同依据和申诉方式。

## 11. 影响评估（DPIA）清单

- [ ] 明确处理者、处理目的和数据生命周期。
- [ ] 证明儿童照片/健康数据是最小必要。
- [ ] 评估误识别、误提示和训练伤害风险。
- [ ] 评估跨平台、第三方模型和 BOKS 内部支持访问。
- [ ] 评估撤回、删除、备份和日志。
- [ ] 评估自动化决策是否对儿童造成不利影响。
- [ ] 评估模型偏差和不同年龄/设备/体型的性能。
- [ ] 形成残余风险、控制措施和上线批准记录。

## 12. 安全事件

1. 发现泄露、越权、错误发布或模型危险输出后立即冻结相关任务/版本。
2. 通过 trace_id 和审计事件确定范围，不在群聊传播原图。
3. 对象存储撤销签名 URL，吊销令牌，隔离受影响服务。
4. 恢复到上一个规则/模型版本。
5. 评估需通知的监护人及依法需要通知的主体。
6. 记录根因、影响、修复和复发测试。

## 13. 合规验收

- [ ] 隐私政策、儿童专门说明和小程序指引已配置。
- [ ] 监护人授权分项、可撤回、可导出和可删除。
- [ ] App Store/Google Play/微信提交材料无诊断性宣传。
- [ ] 所有第三方 SDK 已登记用途、权限和数据流。
- [ ] 已完成数据保护影响评估和产品属性评估。
- [ ] 原图、音频和健康推断不会进入默认模型训练。
- [ ] 越权、注入、文件上传、删除残留和日志泄露测试通过。
