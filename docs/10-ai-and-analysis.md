# 10 评分、姿态分析与 AI 设计

## 1. 总体原则

AI 只负责测量辅助、解释和内容编排，标准规则、安全门禁和数据删除由确定性服务控制。任何模型输出都必须带版本、置信度、输入快照和可审计的规则结果。

## 2. 体测评分引擎

### 2.1 输入

```text
standard_version_id
school_stage
grade_code
sex_code
age_in_months
measurement_date
indicator_values
test_status
```

### 2.2 处理步骤

1. 校验标准版本是 `published` 且在测量日期有效。
2. 根据学段/年级/性别加载项目集合。
3. 校验每个原始值的单位、精度、范围和测量状态。
4. 计算派生指标（如 BMI），保存公式和输入。
5. 查表获取单项标准分。
6. 应用权重、附加分和总分上限。
7. 生成等级和解释。
8. 输出 `calculation_trace`，将每次查表和规则命中记录下来。

### 2.3 规则 DSL

规则建议使用 JSON/DSL，而不是动态执行任意代码：

```json
{
  "indicator_code": "run_50m",
  "population": {
    "school_stage": "primary",
    "grade_code": "grade_2",
    "sex_code": "female"
  },
  "unit": "s",
  "direction": "lower_is_better",
  "weight_percent": 20,
  "score_bands": [
    {"max": 9.8, "score": 100},
    {"min": 9.9, "max": 10.2, "score": 95}
  ],
  "source_ref": {
    "knowledge_version_id": "0190...",
    "page_or_table": "附表"
  }
}
```

生产引擎只允许白名单操作、范围检查和版本化测试。

### 2.4 评分测试

每个规则版本必须包含：

- 边界值；
- 上下一个分档；
- 缺测、免测、补测；
- 单位换算；
- 四舍五入；
- BMI 极值和年龄边界；
- 同一输入重复计算一致性；
- 新旧版本差异快照。

## 3. 体态拍摄协议

### 3.1 标准化条件

- 平整地面、背景简单、光线均匀；
- 手机/相机镜头与目标身体中心高度接近；
- 相机与人体正交，避免广角近拍；
- 儿童赤足或按协议统一鞋袜；
- 头部自然、双脚按脚位线站立、双臂自然下垂；
- 四视角尽量使用同一设备、距离和环境；
- 监护人陪同，儿童可以随时停止。

协议必须提供适合 3—6 岁、6—12 岁、13—18 岁的不同说明，不能假定幼儿能保持成人标准站姿。

### 3.2 质量门禁

质量模型/规则输出：

```text
full_body_visible
single_person
view_alignment
camera_level
lighting
occlusion
pose_compliance
background_quality
quality_score
reasons[]
```

门禁策略：

- 任一硬失败：拒绝生成姿态结论；
- 软失败：允许继续，但报告标记低置信度并建议复拍；
- 质量分只代表照片可分析程度，不代表孩子健康程度。

## 4. 视觉分析流水线

```text
原图
  -> MIME/哈希/恶意文件检查
  -> 人体和视角质量
  -> 关键点检测
  -> 坐标归一化和误差估计
  -> 多视角一致性
  -> 观察性指标
  -> 安全规则
  -> 报告结构化输出
```

### 4.1 可考虑的指标

- 肩部左右相对高度；
- 肩胛/腰线/躯干左右对称观察；
- 躯干相对中线偏移；
- 骨盆标志点相对高度；
- 侧面 C7—耳屏—水平线的研究性姿态指标（符合协议时）；
- 关键点置信度、视角一致性和测量误差。

每个指标必须有：定义、单位、适用年龄、拍摄协议、研究/标准来源、置信度阈值、不可用情形和文案模板。

### 4.2 禁止的自动结论

- 不从普通照片输出 Cobb 角；
- 不诊断脊柱侧弯、颈椎病、骨盆疾病、扁平足或其他疾病；
- 不根据照片推荐矫形器、牵引或治疗动作；
- 不把成人研究阈值直接应用于儿童；
- 不把关键点模型高置信度等同于医学结论高置信度。

## 5. 多视角融合

单视角观察不能替代多视角一致性。融合逻辑：

1. 每个视角独立质量评估；
2. 仅对通过门禁的视角提取指标；
3. 对同一观察在前/后/左/右之间做一致性检查；
4. 一致性低时降级为“需要复拍/人工复核”；
5. 多视角一致也只能提高观察置信度，不能改变非诊断边界。

## 6. 红旗和安全策略

安全问卷和对话中识别：

- 疼痛、麻木、无力；
- 夜间疼痛或发热；
- 步态明显改变；
- 近期快速变化；
- 呼吸困难或运动耐量明显下降；
- 既往手术、严重外伤或正在接受治疗。

命中红旗：

```text
analysis_result = observation_only
training_plan = blocked
next_action = parent_medical_review
```

产品不判断急症程度；必要时提示家长联系当地急救或自行到正规医疗机构就医。

## 7. 训练规划引擎

### 7.1 规则层

先执行安全门禁：

1. 是否有红旗症状；
2. 是否有专业人员限制；
3. 是否有禁忌动作；
4. 是否低于适用年龄；
5. 是否缺少必要输入。

规则通过后再编排动作：

- 目标能力：速度、耐力、柔韧、力量、协调、平衡；
- 体态教育：身体意识、姿势变化、呼吸、轻度活动；
- 频次、时长、强度和休息；
- 器材和场地替代；
- 每周复盘和复测。

### 7.2 内容模型

每个动作内容包含：

```text
exercise_id
name
age_min / age_max
target_capabilities[]
setup
steps[]
dos[]
donts[]
sets / reps / duration
intensity
rest
regressions[]
progressions[]
stop_conditions[]
contraindications[]
content_version
reviewed_by
```

AI 只能从已发布动作库中选择和编排，不能自行创造治疗性动作和剂量。

## 8. 智能对话架构

```text
用户输入
  -> 内容类型/风险分类
  -> 权限和上下文检查
  -> 知识库检索（已发布快照）
  -> 结构化报告/动作库检索
  -> 大模型生成候选回答
  -> 事实/引用/医疗边界/未成年人安全检查
  -> 流式或完整回答
```

### 8.1 RAG 约束

- 检索只读已发布版本；
- 标准数值必须来自结构化规则，不从自然语言段落猜；
- 每个结论保存引用的 `knowledge_version_id`；
- 检索不到可靠依据时，明确说明限制并建议 BOKS 内部人工支持或家长自行就医；
- 不把用户上传的儿童照片作为公共知识。

### 8.2 系统提示策略

AI 系统策略至少包含：

- 产品定位和非诊断边界；
- 未成年人沟通和家长优先；
- 禁止危险训练、疾病诊断和处方建议；
- 体测分数优先引用报告；
- 不编造标准、链接和研究结果；
- 红旗症状的停止训练/就医流程；
- 需要时请求最小必要补充信息。

## 9. 语音和多模态

```text
音频 -> 恶意文件/时长检查 -> ASR -> 用户确认 -> 风险分类 -> RAG/LLM
图片 -> 授权检查 -> 质量门禁 -> 结构化姿态结果 -> 对话上下文
```

- 音频和图片按各自同意范围处理；
- 用户未选择报告/照片时，AI 不得自动读取；
- ASR 不确定时让用户确认，而不是直接执行训练；
- TTS 只播报已通过安全检查的文本。

## 10. 模型版本和评估

每个模型登记：

```text
model_id
task
version
training_data_provenance
license
supported_age_range
supported_devices
metrics_by_slice
known_limitations
approval_status
rollback_version
```

评估分层：

- 年龄：3—5、6—9、10—12、13—15、16—18；
- 性别；
- 设备和摄像头；
- 光照、背景、服装、体型；
- 视角和距离；
- 可用/不可用样本；
- 与人工标注/测量的一致性。

上线门槛不仅看平均指标，还要看最差分层、失败可解释性和安全漏检。模型升级先灰度，报告必须保存使用的版本。

## 11. 人工复核

触发条件：

- 低置信度；
- 多视角不一致；
- 红旗问卷；
- 用户申诉；
- 模型版本变更后的抽样；
- 专业审核员认为规则映射不完整。

人工复核员只能查看授权范围内的最小数据；复核结论不能修改原始照片和原始值，只能追加结构化意见。

## 12. 失败和降级

- 视觉模型不可用：允许保存照片任务，报告状态为“待分析”，不输出猜测。
- 大模型不可用：返回已生成的规则式训练建议和标准引用。
- 知识库不可用：使用当前已发布快照，不抓取临时网页给用户。
- 训练内容不足：显示“暂无适合当前条件的安全计划”，不编造动作。
- 评分规则冲突：进入人工审核，不返回旧版本伪装成新结果。

## 13. AI 验收

- [ ] 模型结果包含版本、置信度、质量门禁和适用范围。
- [ ] 普通照片不输出 Cobb 角或疾病诊断。
- [ ] 红旗症状会阻止强化训练计划。
- [ ] AI 数值回答均能回溯到结构化规则或明确拒答。
- [ ] 多模态输入必须有用户选择和授权。
- [ ] 模型回滚后新任务使用旧版本，历史报告不被重写。
